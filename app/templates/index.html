Leave everything unticked to let the service detect every category it supports. Ticking a subset sends piiCategories, which is a real filter — the service returns only what you ask for. Categories the selected api-version rejects are shown struck through and are dropped from the request rather than failing it.

Entity synonyms none

Context vocabulary that helps the model spot an entity from the words around it — on a form, the label beside the value. Sends entitySynonyms, which only 2026-05-15-preview accepts. It widens detection; it will not make the service recognise a value that does not look like the entity at all.
